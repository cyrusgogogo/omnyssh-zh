# 简体中文术语表

| English | 简体中文 | 说明 |
|---|---|---|
| Dashboard | 概览 | 主机卡片首页 |
| Host | 主机 | 保留用户输入的主机名，不翻译其值 |
| File Manager | 文件管理 | SFTP 双面板界面 |
| Snippet | 命令片段 | 可保存、参数化并批量运行的命令 |
| Broadcast | 批量运行 | 在多台主机上运行同一命令片段 |
| Streamer mode | 演示模式 | 隐藏真实 IP 的显示模式 |
| Key setup | SSH 密钥配置 | 自动生成、复制并验证密钥的流程 |
| System default | 跟随系统 | 根据操作系统语言选择界面语言 |
| Reachable / Unreachable | 可达 / 不可达 | TCP 探测结果 |
| Jump host | 跳板机 | SSH `ProxyJump` 中间主机 |

命令、参数、配置键、路径、主机名、远程输出和协议字段保持原文。产品名称 OmnySSH、SSH、SFTP、PTY、CPU、TCP 等技术缩写不翻译。
